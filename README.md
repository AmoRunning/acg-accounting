# 🐾 吃章记录

面向吃谷人/章子爱好者的徽章采购记账工具，记录章子从打样到到手的全流程，追踪均摊和大货付款状态。

## 技术栈

- React 18 + Vite
- Semi Design (@douyinfe/semi-ui)
- IndexedDB 本地存储

## 功能

- **统计卡片**：打样中、大货中、待付均摊金额、待付大货金额、已到手
- **提醒系统**：今日DDL、今日排期
- **记录管理**：新增、编辑、删除、复制、置顶、排序
- **章子信息**：图片、章名/车名、工艺、镀色、车主、数量、均摊、单价、单个总价、DDL、排期、备注
- **搜索筛选**：按章名/车主/系列搜索，按状态筛选
- **数据备份**：JSON 导入/导出
- **回收站**：软删除、恢复、永久删除
- **图片管理**：压缩上传、全屏预览

## 开发

```bash
npm install
npm run dev
```
